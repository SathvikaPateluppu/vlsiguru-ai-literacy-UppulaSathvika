 # Mission 1: Build the AI and ML Landscape
## Research question: What is artificial intelligence, and where exactly does machine learning fit?
### Artificial Intelligence (AI)?
Artificial Intelligence is a field of computer science that focuses on building systems that can perform tasks that normally require human-like intelligence.
### Machine Learning (ML)?
Machine Learning is a part of AI in which a computer learns patterns from data and uses those patterns to make predictions or decisions.
### Conventional rule-based programming?
In conventional rule-based programming, a programmer writes explicit instructions and conditions that tell the computer what to do.

## Comparision of AI, rule-based programming, and ML

| Aspect | AI | Rule-Based Programming | Machine Learning |
|---|---|---|---|
| Approach | Broad field of intelligent systems | Follows predefined rules | Learns patterns from data |
| Data | Depends on the method | Training data is generally not required | Training data is required |
| Adaptation | Depends on the technique | Rules must be changed manually | Model can be retrained with new data |
| Example | AI assistant | Flag delay above 3 ns | Predict timing failure using past data |

## Relationship Between AI, ML, Deep Learning, Generative AI, and LLMs

- **Artificial Intelligence (AI):** AI is the broad field of creating computer systems that perform tasks requiring abilities such as reasoning, planning, and understanding language.

- **Machine Learning (ML):** ML is a branch of AI in which models learn patterns from data and use them to make predictions or decisions.

- **Deep Learning (DL):** Deep Learning is a branch of ML that uses neural networks with multiple layers to learn complex patterns.

- **Generative AI:** Generative AI refers to AI systems that create new content, such as text, images, audio, or code. Many modern generative AI systems use deep learning.

- **Large Language Models (LLMs):** LLMs are models trained on large amounts of language data to process and generate text. Most modern LLMs use deep learning and can be used in Generative AI applications.

### Relationship

AI is the broad field. ML is one approach within AI, and Deep Learning is a type of ML. Generative AI focuses on creating new content, while LLMs specialize in language-related tasks and are commonly used for text generation.

## Five Distinctions 

| No. | Comparison | Distinction  |
|---|---|---|
| 1 | AI vs Machine Learning | AI is the broader field of making computers perform intelligent tasks. ML is one approach within AI that learns patterns from data. |
| 2 | Rule-Based Programming vs Machine Learning | In rule-based programming, the programmer writes the conditions directly. In ML, the model learns useful patterns from training examples. |
| 3 | Machine Learning vs Deep Learning | ML includes many learning methods. Deep Learning is a subset of ML that uses neural networks with multiple layers. |
| 4 | Deep Learning vs Generative AI | Deep Learning describes a family of learning methods. Generative AI describes systems that create new content. Many Generative AI systems use Deep Learning, but the terms describe different things. |
| 5 | Generative AI vs LLMs | Generative AI includes systems that create different types of content, such as text, images, audio, and code. LLMs focus on language and can be used for text generation and other language tasks. |

## Why automation is not necessarily AI
Automation means a task is performed automatically with little or no human intervention. It can use simple rules, timers, sensors, or programmed sequences without learning or intelligent reasoning.
Examples:
- A light turns on automatically at 6 PM.
- A script automatically backs up files every night.
- A washing machine follows a fixed washing cycle.
These are automated tasks, but they do not necessarily use AI or ML.
An AI system can also be automated, such as a system that automatically detects suspicious transactions using an ML model.
- **Automation describes how a task is carried out;**
- **AI describes the techniques or capabilities used to perform intelligent tasks.**

## Why AI does not always mean ML
AI includes multiple approaches. Some AI systems use explicitly written rules, search algorithms, planning, or logic instead of learning patterns from data.
ML is one part of AI, not the whole of AI.

This means ML belongs within the broader AI field. It does not mean every AI system must use ML.

AI is the broad field, ML learns patterns from data, Deep Learning uses multilayer neural networks, Generative AI creates new content, and LLMs focus on language-related tasks.
