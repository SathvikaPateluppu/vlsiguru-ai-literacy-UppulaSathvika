## Overview

Week 02 focuses on understanding how machine learning works, how different learning approaches use data and feedback, how models are evaluated, and when machine learning is an appropriate solution to a problem.

This week's activities also explore how machine learning concepts can be connected to VLSI Physical Design and semiconductor engineering.

## Learning Objectives

- Understand the relationship between Artificial Intelligence, Machine Learning, Deep Learning, Generative AI, and Large Language Models.
- Learn about datasets, samples, features, labels, and data quality.
- Compare supervised, unsupervised, reinforcement, and self-supervised learning.
- Understand classification, regression, clustering, and other machine learning task types.
- Explain the difference between an algorithm, a model, training, and inference.
- Understand evaluation metrics, overfitting, underfitting, and generalisation.
- Identify common machine learning failure modes and the importance of human oversight.
- Understand when to use machine learning instead of a rule-based approach.
- Explore how machine learning can support semiconductor engineering and VLSI Physical Design.

## Semiconductor Engineering Connection

This week's work explores how machine learning may support semiconductor engineering and VLSI Physical Design.

One possible application is timing prediction using historical design characteristics. Machine learning could help estimate timing-related outcomes and identify designs that may need further investigation.

The example connects the engineering problem with relevant data, the machine learning task, evaluation methods, possible benefits, and limitations.

Machine learning predictions can support engineering decisions, but they should not replace required static timing analysis, verification, or sign-off procedures.
