# Week 01 AI Assistant Comparison

## Common Prompt 1
> "Explain the difference between Machine Learning, Deep Learning, and Generative AI to a beginner engineer, and provide an everyday example for each."

## Tool 1: ChatGPT
* **Answer Summary:** Explained ML as learning from data, Deep Learning as using neural networks, and Generative AI as creating new content, with simple everyday examples.
* **Strengths:** Clear, simple, and easy for a beginner to understand.
* **Weaknesses:** The explanation was high-level and did not cover some technical details.

## Tool 2: Gemini
* **Answer Summary:** Explained ML as learning patterns from data, Deep Learning as using multi-layer neural networks, and Generative AI as creating new content, with everyday examples.
* **Strengths:** Good technical distinctions and concise explanations.
* **Weaknesses:** Some explanations were slightly more detailed and technical.

---

## Common Prompt 2
> "What is the forward voltage of a typical silicon PN-junction diode?"

## Tool 1: ChatGPT
* **Answer Summary:** Explained that a typical silicon diode has a forward voltage of about 0.7 V.
* **Strengths:** Clear and simple explanation that is easy for a beginner to understand.
* **Weaknesses:** The answer may be too general if it does not mention that forward voltage changes with current and temperature.

## Tool 2: Gemini
* **Answer Summary:** Explained that the forward voltage of a typical silicon diode is around 0.7 V and that the actual value can vary with operating conditions.
* **Strengths:** Included an important qualification about current and temperature.
* **Weaknesses:** The explanation was slightly more detailed than needed for a basic question.
