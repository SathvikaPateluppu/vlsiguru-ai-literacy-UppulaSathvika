## 5. What I Learned About OpenROAD

OpenROAD is an open-source tool that supports automated digital chip design and implementation. It is relevant to Physical Design because it provides tools for different stages of the digital implementation flow.

A simplified Physical Design workflow includes:

1. Floorplanning
2. Placement
3. Clock Tree Synthesis (CTS)
4. Routing
5. Timing and design analysis

OpenROAD helps users explore and automate parts of this workflow. Learning about it helped me understand how Physical Design tools are used to transform a digital design into a physical implementation.

I also learned that understanding the tool's documentation and checking the results of each stage are important when working with VLSI design tools.
