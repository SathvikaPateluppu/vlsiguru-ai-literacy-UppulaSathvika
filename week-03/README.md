## Responsible AI Practices

- Verify important technical claims using reliable sources.
- Compare AI-generated explanations rather than relying on a single answer.
- Review AI-generated technical information critically.
- Avoid uploading confidential RTL, netlists, timing constraints, or proprietary design data to public AI tools without authorization.
- Review and test AI-generated code before using it.
- Take responsibility for understanding and validating submitted work.
