## 5. Neural Network Architecture

A neural network consists of three main parts:

1. **Input Layer:** Receives input features.
2. **Hidden Layers:** Process information and learn patterns.
3. **Output Layer:** Produces the final prediction.

## 6. Practical Experiment

**Tool:** TensorFlow Playground

Link: https://playground.tensorflow.org/

I experimented with two network configurations:

- Baseline: One hidden layer with four neurons.
- Modified: Two hidden layers with four neurons in each layer.

The experiment helped me understand how changing network architecture affects learning capacity.

## 8. Key Learnings

- Neural networks learn patterns from training data.
- Hidden layers help process information.
- Backpropagation helps reduce prediction errors.
- Learning rate influences the training process.
- Increasing network complexity does not always improve performance.
- AI and machine learning have potential applications in VLSI Physical Design.
