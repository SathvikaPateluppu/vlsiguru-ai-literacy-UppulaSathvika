
# Week 04 — Learning Reflections

## 1. What I Learned This Week

This week, I learned the basic working principles of neural networks and how they learn patterns from data.

I understood that a neural network consists of input layers, hidden layers, and output layers. Each layer plays a role in processing information and producing predictions.

I also learned about forward propagation, loss calculation, backpropagation, optimizers, learning rates, and epochs.

## 2. My Understanding of Neural Networks

Earlier, I thought neural networks were simply computer systems that produce answers from data.

Now, I understand that they learn by adjusting weights and biases based on prediction errors.

The learning process involves:

1. Receiving input data.
2. Processing the input through hidden layers.
3. Producing an output.
4. Calculating the prediction error.
5. Updating weights using backpropagation.
6. Repeating the process to improve predictions.

This helped me understand how a neural network gradually learns from examples.

## 3. My TensorFlow Playground Experience

I used TensorFlow Playground to explore how neural network architecture affects learning.

I started with a simple network containing one hidden layer and then explored a modified network with two hidden layers.

This comparison helped me understand that adding hidden layers increases the network's complexity and learning capacity.

I also understood that increasing the number of layers does not automatically guarantee better results. The network configuration and training process are important.

## 4. Connection to My Physical Design Track

As a Physical Design learner, I found it interesting to connect neural networks with possible VLSI applications.

For example, machine learning can be explored for predicting congestion hotspots during placement.

A model could learn from features such as placement density, cell distribution, and routing resources to estimate congestion risk.
